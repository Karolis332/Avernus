- **Slug conventions discovered:**
  - Monsters: plain kebab-case (e.g. `bone-devil`, `cult-fanatic`, `night-hag`)
  - Spells: prefixed with source — `srd-2024_<name>` (e.g. `srd-2024_banishment`). Bare slug `wish` also works for that spell only.
- **Pre-canned query patterns (also in primer's MID-SESSION REQUEST PROTOCOL):**
  - `mcp__open5e__get { resource_type: "monsters", slug: "<kebab>" }` — full statblock
  - `mcp__open5e__get { resource_type: "spells", slug: "srd-2024_<name>" }` — RAW text
  - `mcp__open5e__search { query, resource_type, limit }` — search across SRD 2014/2024/ToB
  - `mcp__open5e__list { resource_type, cr, type }` — filter (e.g. all CR 12 Fiends)
  - `mcp__open5e__rag_search { query, mode: "hybrid" }` — RAG over docs corpus
  - `mcp__open5e__batch_get { requests: [...max 50] }` — batch full-encounter prep
- **Known errata baked into the primer:**
  - Cult Fanatic HP is **22** (corrected from prior 33 in earlier prep notes)
  - SRD 2024 Wish RAW = STR 3 for **2d4 days** + 1d10 necrotic/spell level until LR + 33% no-repeat. Primer keeps homebrew but documents the deviation.
  - Bone Devil **flies** (40 ft) — use vertical axis in combat.
